# 💳 Credit Card Users Churn Prediction

## 📌 Project Overview (English)

Banks generate significant revenue from credit card usage through annual fees, transaction fees, interest, and penalty charges. A decline in active credit card users directly impacts profitability.

This project analyzes customer data to identify churn patterns and predict which credit card users are likely to stop using their cards. The insights help banks design appropriate fee structures, improve customer retention, and make data-driven business decisions.

We apply advanced machine learning techniques, including ensemble models, to build a robust and interpretable churn prediction system.

## 📌 プロジェクト概要（日本語）

銀行は、クレジットカードの年会費、取引手数料、利息、延滞料金などから大きな収益を得ています。
クレジットカード利用者の減少（チャーン）は、銀行の収益に直接的な影響を与えます。

本プロジェクトでは、顧客データを分析し、クレジットカードの解約・利用停止につながるパターンを特定し、
将来チャーンする可能性の高い顧客を予測します。

この分析結果は、適切な手数料設計や顧客維持戦略の改善に活用できます。

## 🎯 Business Objective (English)

Predict churn-prone users before they stop using the card
